# لوحة إدارة تطوير الأكاديمية

## منهج التنفيذ
كل حزمة لها نتيجة يمكن تجربتها، وقواعد بيانات، واختبارات، وفحص نشر. احتفاظ بالبيانات الموجودة، وعدم خلط إعادة التصميم بإطلاق نظام إنتاجي دون الخادم.

| الحزمة | الحالة | معيار الإنجاز |
| --- | --- | --- |
| مراجعة السوق والمنتج | مكتملة | 4 مصادر رسمية مقروءة؛ مصدر خامس محجوب موضح؛ خطة منتج محفوظة |
| إعادة تصميم الواجهة والكاليندر وملف اللاعب | منفذة | هوية جديدة، تقويم شهر/أسبوع تفاعلي، بحث سريع، وتبويبات بيانات فعلية |
| مركز التشغيل ودليل اللاعبين | منفذة | بيانات الفرع والرياضة من العلاقة بالجروب، وليست تغيير عناوين فقط |
| الجروبات والجدول | منفذة | إنشاء جروب وحصة محفوظين، مع رفض تعارض الجروب والمدرب والمكان |
| التحصيل والطلبات | منفذة في السجل المحلي | اختيار اللاعب من النطاق، تحصيل جزئي واستكمال، إيصال يعرض الفرع الصحيح |
| الأسرة والتسجيلات المتعددة | التالية | ولي أمر مرتبط بأطفال حقيقيين في السجل، طفل له أكثر من تسجيل دون تكرار ملفه |
| تقدم الرياضات | التالية | تاريخ محاولات وتقييمات واختبارات مؤرخ؛ لا فقد بعد إعادة التحميل |
| الخادم والهوية | غير منفذة | دخول فعلي وصلاحيات على API وعزل أكاديميات وتزامن أجهزة ونسخ احتياطية |
| المصروفات والرواتب والربحية | غير منفذة | فصل التحصيل عن الإيراد المحاسبي والربح، ومصروفات معتمدة مرتبطة بالفروع |
| الرسائل والتكاملات الخارجية | غير منفذة | حالة إرسال فعلية وإعادة محاولة وسجل فشل وتهيئة آمنة للمفاتيح |

## الثغرات المتبقية المؤكدة
- عائلات الرياضات ومهاراتها وحجوزاتها القديمة مستقلة عن السجل التشغيلي المحلي.
- مصدر الجداول الحالي موارد ومدربون بأسماء نصية؛ في نموذج الإنتاج تصبح معرفات من سجلات موارد وموظفين.
- اشتراك اللاعب مرتبط بجروب واحد؛ المرحلة التالية تفصل الملف عن تسجيلات البرامج.
- الوردية القديمة مشتركة لسجل العرض، وليست خزائن مستقلة لكل فرع.
- إدارة الفروع والصلاحيات والتغذية والتواصل تحتوي على وظائف توضيحية لا تكاملات حقيقية.
- حضور بعض بيانات العرض القديمة لا يحمل مدربًا ومكانًا؛ لا يُفترض اكتمال كشف تعارضها.

## فحوص القبول
- التسجيل بالفرع ثم الرياضة ثم الجروب.
- لا تظهر معاملات لاعب من فرع آخر في نطاقه.
- إنشاء جروب وحصة ثم إعادة التحميل دون فقدهما.
- رفض موعد متداخل، والسماح بموعدين متجاورين.
- جميع روابط القائمة تصل لصفحة تعمل.
- لا تجاوز أفقي في الصفحات الأساسية بعرض 390 بكسل.
- حفظ نسخة إعدادات الاستضافة قبل تعديلها، ومراجعة الروابط القديمة عند النشر.
